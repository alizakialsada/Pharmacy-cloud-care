V5 changes
- Department Filter added to dispensing workspace. It filters active patients for the currently selected pharmacy.
- QCH complete dispensing history now also reads qch-history.js so OPD2, INPATIENT, IV, NARCOTICS, ER and other pharmacy histories are available when present in source data.
- Each normal Order History remains pharmacy-specific: only records matching the currently selected pharmacy are shown.
- History is newest first and includes medication search + department filter.
- IV order button becomes Add IV Order in IV pharmacy and opens the IV Order Template. IV history displays IV details when those fields exist.
- Doctor accounts can open both Doctor View and Order History. Both are read-only; renew/cancel/reprint/action controls are suppressed for doctors.
