SAFETY RULES USED
- Existing patient records were not deleted.
- Existing history rows were not deleted.
- Existing values were preserved; blank demographic fields were filled only when the new files had a value.
- Patient ID from the source files was treated as MRN, NOT National ID.
- History rows were added only when a matching date + pharmacy + medication + department event did not already exist.
- Rows marked Not Dispensed were not inserted into dispense history.
- Rows marked Dispensed but missing both dispense date/store were not inserted into history.
- qch-orders-data.js / active order source was NOT changed.
